# Nomos atlas (site)

Next.js 16, TypeScript and Tailwind CSS. The site is in English by default, with a Portuguese toggle; all texts live in [`src/i18n/dicionarios.ts`](src/i18n/dicionarios.ts).

| Page | What it shows |
| --- | --- |
| `/` | Official curtailment in the Northeast, map of featured plants, forecast windows by day, the three kinds of curtailment and the price at the floor |
| `/plants/[id]` | One plant: why it is curtailed, forecast windows (Reserve), month × hour heat map, recent windows with the ONS verdict (Replay), backtest |
| `/track-record` | Live scoreboard, curtailment by reason, model comparison, calibration, SHA-256 fingerprints |
| `/method` | What is real, estimated and simulated; definitions; open data downloads; limitations |
| `/verify?tx=…` | The public proof of a reservation: payment, receipt, execution and ONS stamp, read from Solana |

API routes (server only; they hold the test-wallet keys from environment variables):

| Route | What it does |
| --- | --- |
| `POST /api/recibo` | Checks a reservation on-chain and issues what is missing: the receipt (phase 1) and, once the ONS has published, the stamp (phase 2). Idempotent. |
| `GET/POST /api/previsao` | Reads or records the SHA-256 of the published forecast file on Solana |
| `POST /api/carimbar` | Issues missing receipts and stamps for every reservation (used by the daily update) |

## Data

The site computes nothing at request time: it reads `src/data/*.json` and serves `public/data/`, both generated by `python dados/scripts/atlas.py` (run from the repository root, after `dados/scripts/etapa1.py`). Do not edit them by hand.

The hourly PLD comes from the CCEE open data portal, which blocks automated downloads: download `pld_horario_2026.csv` in a browser and save it to `dados/ccee/`. Hours without a published price use the 2026 floor (R$ 57.31/MWh) and are marked as estimated.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run start
```

To reserve windows locally, put the test-wallet keys in `.env.local` as `VC_CHAVE_USINA`, `VC_CHAVE_OPERADOR` and `VC_CHAVE_PLATAFORMA` (JSON arrays; generate with `node scripts/gerar-carteiras.mjs`). `node scripts/compra-teste.mjs <PLANT_ID> <YYYY-MM-DD[THH:MM]>` makes a test reservation without Phantom.

Map: Leaflet with OpenStreetMap tiles (no API key). Plant locations are approximate, by municipality: `dados/config/localizacao_usinas.json`.
